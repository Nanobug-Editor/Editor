## 测试接缝

| 接缝 | 可发现的问题 | 不覆盖的部分 |
| --- | --- | --- |
| 公开 UI 声明、能力协商和管理器发布 | 非法场景、版本/权限、身份、配额、原子更新和撤销错误 | OS 输入、实际像素和显示帧耗时 |
| 实际 WASM 包经公开管理器进入宿主 | SDK/打包、序列化、真实实例生命周期与消费者可替换性 | 独立于 OS 的模拟不能证明输入法/辅助功能正确 |
| 原生 GPUI 交互与可见结果 | 真实布局/绘制、DPI、焦点、IME、辅助功能、拖放及帧开销 | 未实测平台的兼容承诺 |

这些接缝沿用方案；每次 TDD 循环只增加一个可观察行为的失败测试和足够的实现。阶段内先定向验证，交付时执行仓库完整门禁；没有新风险不反复清理或重跑相同基线。固定包版本、工具链、数据种子和运行参数，实际 ignored 测试显式构建并执行。
