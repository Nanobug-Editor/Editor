# 03：原生混排与数据交换

**来源：**[Canvas 扩展方案](../../specs/canvas-protocol-extension.md)。稳定标识：`canvas-protocol-extension/03-native-transfer`。

**What to build：**表格和流程图插件在场景坐标中使用原生控件、菜单和提示，通过多格式剪贴板与通用拖放交换文字、图片及有界自定义数据。

**Blocked by：**[02 / #129 — 可编辑目标与语义](https://github.com/Nanobug-Editor/Editor/issues/129)。

**Status：**AC1–AC6 已验收，等待普通提交、推送与 [#130](https://github.com/Nanobug-Editor/Editor/issues/130) 关闭读回；[最终证据与冻结输入](../../verification/canvas-native-transfer-2026-10-26.md)。前置 #129 已读回 closed/completed；未合并 main。

**Why separate：**原生控件、菜单锚点及拖放共享 02 的焦点/目标/语义生命周期，但数据交换引入独立协商、授权和系统适配，可以作为独立可交付行为验证。

## Acceptance criteria

- [x] AC1：已有原生控件按场景锚点在前景层定位/裁剪，随滚动缩放移动且保持稳定身份；旋转/倾斜原生控件明确拒绝，焦点返回和遮挡行为正确。
- [x] AC2：提示和菜单使用现有本地实现，新增锚点随目标/显示版本映射并夹持窗口边缘；目标撤销和模态切换关闭旧弹层。
- [x] AC3：多格式剪贴板按需枚举/读取/写入纯文本、惰性 HTML、PNG 与包命名空间格式；表格可交换 TSV/HTML，原纯文本入口行为保持。
- [x] AC4：统一拖放 offer 的进入/移动/离开/放下/取消与 OS 拖入/拖出正确；仅在读取选定格式时加载数据，格式优先级和取消结果可观察。
- [x] AC5：外部文件用该次用户拖入的受控导入句柄读取；工作区写入仍检查权限，跨插件不借用来源授权，失效/外实例/超额数据被拒绝，HTML 不执行或加载外部内容。
- [x] AC6：实际表格/流程图包的原生控件、中文 IME、语义、菜单和传输可组合，旧文档图片输入、剪贴板及普通布局消费者通过受影响回归。

## Verification

AC1/AC2/AC6 通过真实 GPUI 布局、焦点、输入法、窗口边缘和语义结果验收；AC3～AC5 由公开传输/剪贴板/管理器及实际包验证格式选择、权限、字节预算、撤销和跨实例隔离，再补 OS 原生拖入/拖出与系统剪贴板实测。各项失败仅影响原请求和资源，不能遗留捕获、弹层或文件权限。

本单执行仓库阶段门禁、受影响宿主原生/定向测试与真实包验证；04 承担传输/控件与场景补丁、隐藏及热更新组合后的最终验收。
