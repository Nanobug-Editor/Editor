# 05：让异步复制粘贴始终绑定原目标

稳定标识：`shared-ui-foundation/05-targeted-clipboard`。

**Status:** planned／未开始。仅本地工单；本轮不修改剪贴板实现。

**What to build:** 宿主用户操作与插件定向命令使用同一原生目标模块完成文本复制／粘贴，复用既有 `ui.clipboard` 和 `clipboard` 权限。异步读取后仍校验原目标，不随当前焦点变化误贴；保留旧裸剪贴板请求的准入含义。

来源：[规格 D03–D10，F12–F13、F20](../../specs/shared-ui-s0-s1.md)。

**Blocked by:** [03：让命令固定原生目标并安全恢复焦点](03-targets-focus-commands.md)。不依赖 04 的公开文本转换操作；使用 03 的原生受控读取／变更接缝和同一权限规则。

**拆分依据：** 系统剪贴板有异步读取及不可回滚的外部写入效果，能够独立交付和验收，不需要先完成翻译。

## Acceptance criteria

- [ ] AC1：原生宿主与插件目标复制／粘贴进入同一本地目标实现，系统读写复用既有接口，不新增第二套剪贴板接口或 `clipboard.read/write` 权限。
- [ ] AC2：插件定向复制检查源文本读取权限和敏感标记，粘贴检查原目标写入权限；原生普通粘贴不因新增功能重复索取插件授权。
- [ ] AC3：读取前捕获原目标及守卫；读取期间失焦不会改投，原目标隐藏／关闭／更换或文本／选区／IME 改变时拒绝旧粘贴。
- [ ] AC4：一次合法粘贴构成该目标一次原生编辑和 Undo，不能写只读目标、自动保存或清空正在组合的输入。
- [ ] AC5：空剪贴板／空文本与缺权限、取消、超时、超限、平台执行失败可区分；1 MiB 写入和统一请求边界有测试。
- [ ] AC6：取消 effect 与实际 OS 副作用一致；系统剪贴板写入已完成时不承诺恢复旧内容，迟到回调不得再编辑或发第二个终态。
- [ ] AC7：未升级既有剪贴板契约的包保留其原有准入含义；新定向目标命令未协商时明确失败，SDK 与授权提示同步。

## Verification

| 验收项 | 方法与预期结果 |
| --- | --- |
| AC1–AC2／F12、F20 | 两条真实入口配合公开 Manager；检查安装权限不足、目标读取／写入权限不足及敏感源拒绝 |
| AC3–AC4／F12 | 延迟读取系统文本，期间切焦点、改变选区、进入 IME 或关闭原目标；新目标保持不变，合法粘贴可一次撤销 |
| AC5／F13 | 自动覆盖空值、大小、非法输入与终态，再用 Windows 原生剪贴板验证可见结果 |
| AC6／F13 | 门前／门后取消和接收实例退役；写入 OS 的文本与请求 effect 一致，不假称回滚 |
| AC7 | 既有剪贴板消费者回归及新能力缺失负例，不建立旧协议运行兼容分支 |

实现时遵守共同检查和实际剪贴板回归。隔离测试输入及清理自己的测试内容，避免把用户剪贴板内容写入日志；跨交互并发由 07 验证。
