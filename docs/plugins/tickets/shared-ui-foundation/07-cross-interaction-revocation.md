# 07：在途交互撤销与共享接入联合验收

稳定标识：`shared-ui-foundation/07-cross-interaction-revocation`。

**Status:** planned／未开始。仅本地工单；尚无实现或验收通过结果。

**What to build:** 在同一真实窗口让文本工具、异步剪贴板和文件／文本投递同时使用目标基础，验证焦点切换、模态覆盖、UI 重建、权限撤销及实例退役时，在途操作一致失效或仅提交到仍有效的原目标。这里的“撤销”指在途取消和权限／资源撤销，不新增全局 Undo。

来源：[规格 D03–D10、F16–F20](../../specs/shared-ui-s0-s1.md)。

**Blocked by:**

- [04：在三类文本区域定向读取并替换原目标](04-scoped-text-tools.md)。
- [05：让异步复制粘贴始终绑定原目标](05-targeted-clipboard.md)。
- [06：在宿主与插件间受控投递文本和文件](06-native-drag-drop.md)。

**拆分依据：** 独立切片通过后，公共目标、完成门、事件流及撤销路径仍可能在组合交互中冲突；该独立集成门槛决定 G1-shared。工单不重复各单完整行为矩阵，不依赖 WebView 已可行。

## Acceptance criteria

- [ ] AC1：文本转换等待期间切焦点、关闭或隐藏原目标，再完成粘贴／拖放，旧转换不覆盖任何新目标，也不错误清除有效的新输入。
- [ ] AC2：剪贴板读取与文件载荷准备同时在途时禁用插件、更新实例或撤销信任，迟到结果一致被拒绝，未交付授权及订阅无残留。
- [ ] AC3：模态打开／关闭、UI 重绘及节点同 ID 重建之后，焦点恢复不覆盖用户新选择；旧代际无权写入，新目标自己的正常交互仍工作。
- [ ] AC4：原生变更、Change 汇入、结果回执及订阅事件跨流交错时，回执仍是本次精确版本；首终态不可变，门后停止等待不被误报为未执行。
- [ ] AC5：慢消费者导致队列溢出时，恢复流程明确且有界；快照与订阅交界处的变化被快照水位或后续事件覆盖，其他实例／目标不被连带撤销，资源计入统一额度。
- [ ] AC6：宿主和插件的相同行为使用同一本地模块，字段修复在两种调用方同时生效；未增加第二份文本、撤销栈或测试专用公共操作。
- [ ] AC7：能力与权限缺失、跨实例句柄、敏感与只读区域分别产生规格错误；旧剪贴板／选择资源和显式后台文档行为无回退。
- [ ] AC8：04–06 的证据及联合证据完整，深浅主题、中英文、字号缩放、键盘、中文 IME、滚动／DPI 和基础无障碍完成相关回归；未运行项如实列出后才能判定 G1-shared。
