# 03：让命令固定原生目标并安全恢复焦点

稳定标识：`shared-ui-foundation/03-targets-focus-commands`。

**Status:** planned／未开始。仅本地工单；不表示已授权开始代码实现。

**What to build:** 用户从编辑器、普通输入和只读文本启动命令，宿主与插件均通过同一原生目标模块获得密封身份、能力描述和守卫，执行支持的全选／原生 Undo／Redo 等命令，并在交互结束后安全恢复焦点。必要的受控读取和原子变更内部接缝在本单形成，供后三条交互切片使用；不开放任意界面枚举或全局文本导出。

来源：[规格 D01、D03–D08、D10，F05–F08、F18、F20](../../specs/shared-ui-s0-s1.md)。

**Blocked by:** [01：记录宿主与插件输入的共享行为基线](01-shared-input-baseline.md)。

**拆分依据：** 三条交互共同依赖目标身份、原子守卫、焦点和撤销。与首个真实命令场景一起交付该必要接缝，避免先建立无消费者的完整抽象层。

## Acceptance criteria

- [ ] AC1：三类目标可经宿主直接调用和公开插件入口取得不透明引用；元数据不包含正文、秘密或可替代授权的路径，不支持后台全局枚举。
- [ ] AC2：用户动作时固定目标；后来焦点变化不改投新目标。全选和支持的 Undo／Redo 只作用于原目标，不支持的命令返回 `UnsupportedOperation`。
- [ ] AC3：区分目标代际、内容 revision、选区 epoch、输入 epoch 与 UI revision；同 ID 重建、同路径重开和选区 ABA 拒绝旧守卫，纯外观更新不误使正文过期。
- [ ] AC4：菜单／模态结束后只在仍拥有焦点、目标有效且用户未选择新焦点时恢复；IME 组合不被远程聚焦或命令强制中断。
- [ ] AC5：隐藏、卸载、换源、信任撤销或任一相关实例退役均撤销呈现租约及回调；新代际不能复用旧句柄，现有显式后台文档操作不受新增呈现规则破坏。
- [ ] AC6：`ui.targets`、`ui.focus` 及相关权限／命令授权按规格接入全部准入与 SDK；受理与提交共用既有完成门和错误，不能绕过跨实例及范围限制。
- [ ] AC7：元数据事件有目标序号、明确因果关联和有界队列；首次／恢复订阅原子地建立订阅并返回带水位快照，交界处发生变化也不会遗漏；清理不依赖插件消费终止通知。
- [ ] AC8：宿主与插件使用同一本地实现和原生状态，未建立第二份文本／Undo、第二套取消源或测试专用公共操作。
- [ ] AC9：Undo／Redo 要求用户明确的目标级历史动作；翻译选区或整字段读取租约不能用于扩大历史写入范围，越权返回 `PermissionDenied`。
