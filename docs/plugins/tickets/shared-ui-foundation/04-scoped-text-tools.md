# 04：在三类文本区域定向读取并替换原目标

稳定标识：`shared-ui-foundation/04-scoped-text-tools`。

**Status:** planned／未开始。仅本地工单；本轮不编写翻译插件或宿主代码。

**What to build:** 用户在编辑器、普通输入或只读定义弹窗选择文本工具，插件通过公开目标契约读取获准内容，完成确定性转换，再替换原可编辑目标或呈现只读结果。翻译策略留在插件；本单不依赖在线翻译，不增加单一插件专用接口。

来源：[规格 D03–D08、D10，F08–F11、F20](../../specs/shared-ui-s0-s1.md)。

**Blocked by:** [03：让命令固定原生目标并安全恢复焦点](03-targets-focus-commands.md)。

**拆分依据：** 跨区域内容导出和版本化变更具有独立权限与竞态要求，完成后可以独立演示文本工具，不依赖剪贴板或拖放。

## Acceptance criteria

- [ ] AC1：三类区域均可在用户明确指定工具后读取获准文本；普通 UI 的新读写权限与文档原有 `editor.read/write` 分开，元数据引用不自动变成正文授权。
- [ ] AC2：选区与整字段是不同动作；空选区返回空值，不回退读取全字段。UTF-8、大小上限、敏感字段和跨实例拒绝均遵守规格。
- [ ] AC3：转换结果只针对原身份、范围和守卫；焦点移到另一可见目标不改投，内容／选区／输入变化后拒绝旧结果，纯外观更新不误拒绝。
- [ ] AC4：编辑器与普通输入各形成一次本地原生替换和 Undo；只读弹窗只能展示结果，不能被替换或隐式保存。
- [ ] AC5：IME 组合中捕获或提交返回 `InvalidState`，不强制结束或自动排队到未来状态；组合结束后旧输入守卫不能继续使用。
- [ ] AC6：取消与原子门只有一个执行胜者；回执包含此次精确提交版本、选区和因果序号，不因 deferred 完成前再次键入而改读最新版本。
- [ ] AC7：交付前关闭、隐藏、禁用、撤销信任或退役接收实例，不展示迟到结果、不抢焦点；已执行的编辑不得被错误报告为 `NotExecuted`。
- [ ] AC8：不同流的结果／事件乱序、相同请求轮询及旧提案重放不重复编辑；权限、过期、只读、超时及额度错误可区分。
- [ ] AC9：不声明新文本能力／权限的现有插件仍可使用自有 Input／Textarea 接收 Change、发布 value/value_revision 并正常输入回显；只有主动调用新增目标读写才要求新准入。

## Verification

| 验收项 | 方法与预期结果 |
| --- | --- |
| AC1–AC2／F08–F09 | 固定包经公开 Manager，以确定性文本转换分别操作三类区域；覆盖空选区、整字段、中文／非 BMP 和额度边界；敏感输入不导出 |
| AC3／F09 | 在等待转换时改变焦点、原选区或内容，再返回结果；仅仍有效的原目标可被修改 |
| AC4／F10 | 观察文本、选区、一次 Undo／Redo、未保存状态与只读结果；不依据内部缓存判断成功 |
| AC5 | 真正中文组合开始／提交／取消期间交付结果，原生候选和输入保持正确 |
| AC6／F10–F11 | 使用现有请求接缝控制门前取消、门后停止等待，以及 Change 与 deferred 回执间再次键入／关闭的竞态 |
| AC7–AC8／F11、F20 | 迟到回调、跨流顺序及重复消费；终态不可变，已执行副作用与取消 effect 一致，错误不用消息文本解析 |
| AC9／F20 | 当前基线插件不声明新能力，验证自有字段输入及回显；尝试主动读取宿主其他目标时仍得到能力／权限拒绝 |

实现时执行共同检查门禁和相关原生文本回归；不引入第二份文档或全局 Undo。07 负责与另外两条交互同时在途的联合验收。
