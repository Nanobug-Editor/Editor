# 10 更新与上下文故障恢复

状态：已发布 [#117](https://github.com/Nanobug-Editor/Editor/issues/117)，待依赖验收。用户已授权自主安排顺序、并行实施与子代理；验收完成后才提交完成状态。

## What to build

更新、下载失败、离线、工作区撤权和某一后端退出时，保留或恢复可用兼容组合，准确撤销旧资源，不影响无关上下文和已支持历史版本。

## Acceptance criteria

- [ ] 候选准备失败保留旧实例；激活失败恢复旧包和受管数据，不承诺恢复进程内存。
- [ ] TS 更新与 Vue 适配范围不兼容时保留可用组合或拒绝切换，不静默降低已验收支持。
- [ ] 下载取消、坏摘要、离线缓存、共享产物租约与回滚收据真实验证。
- [ ] 一个后端退出仅影响相应上下文，遵守有限重试；另一个 Vue 版本仍可用。
- [ ] 撤销信任、关闭工作区和卸载任一协作方后，无进程、通道、请求、映射或旧诊断残留。
- [ ] 中英文状态、失败阶段与恢复入口准确，正常调用不反复弹权限确认。
