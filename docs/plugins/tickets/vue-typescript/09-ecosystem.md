# 09 专门生态插件组合

状态：拆分待确认，未发布。

## What to build

专门插件通过公开角色贡献模板转换、样式处理、框架配置或类型适配；Vue 与 TS 按兼容信息组合结果，无需在宿主或 Vue 核心路由中加入插件 ID 分支。

## Acceptance criteria

- [ ] 竞争单选提供者和独立可组合扩展分别发现；不把普通服务 Open 误当广播。
- [ ] 配置协作发生在异步准备阶段，不在既有只读语言 hook 中调用插件服务。
- [ ] 转换结果携带源快照与映射，组合后仍能定位、诊断与生成安全编辑。
- [ ] ABI、顺序或配置冲突显式报告；扩展更新/卸载后旧绑定与映射失效。
- [ ] 至少一个宿主从未认识的真实测试扩展可安装、替换、移除；不据此宣称 Pug/Stylus/Nuxt 正式业务插件已完成。
