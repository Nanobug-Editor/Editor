# 02 子项目语言绑定与按需准备

状态：拆分待确认，未发布。

## What to build

同一单根工作区的多个子项目可以绑定不同分析实例和工具计划。主提供者选择、项目上下文、配置代次与依赖准备共同决定文档路由；只在获得授权且存在实际需求时准备对应工具。

## Acceptance criteria

- [ ] 相同语言的两个子项目同时分析，不再被合并为一份按语言全局缓存的服务。
- [ ] 提供者和上下文由公开贡献与用户选择确定，宿主不按 Vue、TS 或服务器名称分支。
- [ ] 显式选择不被新增提供者覆盖；根路径、符号链接和实例归属经过校验。
- [ ] 缺失依赖的准备与语言钩子分离，可取消、去重、离线复用且不会静默升级插件。
- [ ] 配置变化只重新解析受影响上下文；乱序准备结果不能替换更新的绑定。
- [ ] 使用未知语言真实包验证上述行为，不增加测试专属宿主接口。
