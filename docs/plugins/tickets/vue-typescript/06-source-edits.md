# 06 跨文件重构与自动导入

状态：拆分待确认，未发布。

## What to build

Vue 与 TS 的符号重命名、补全附加导入经过可逆映射生成完整源文件编辑计划，统一进入原生预览、版本校验、提交和分组撤销。目标包括已打开脏文件与未打开文件。

## Acceptance criteria

- [ ] 跨组件与 TS 的符号重命名包含全部必要编辑；用户预览和取消均可观察。
- [ ] 自动导入的主编辑与附加编辑一起校验和应用，不执行有效前缀。
- [ ] 任何路径越界、只读目标、源/目标版本冲突、必要映射缺失都拒绝整个计划。
- [ ] 应用通过原生文档和通用事务，不直接保存原本未保存的文件；分组 Undo 可恢复。
- [ ] 不支持的文件移动、资源操作和任意 LSP command 被明确拒绝。
- [ ] 通过未知语言夹具复用相同编辑能力，不为 Vue 增加特例。
