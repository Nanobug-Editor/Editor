# 04 Vue 多后端首次宿主分析

状态：拆分待确认，未发布。

## What to build

用户安装一个独立 Vue 插件，在 Vue 2.6、2.7、Vue 3 子项目中自动选择已验证的兼容后端。Vue 消费 TS 提供者的上下文和引擎，提供 SFC/模板语义与版本化适配资源，首次在 Nanobug 中获得可观察语言分析。

## Acceptance criteria

- [ ] 三类子项目同时打开，后端、配置和服务实例正确分离。
- [ ] 依赖声明、锁文件、实际安装信息与显式覆盖有可追溯证据；未知或冲突时提示，不默认最新版。
- [ ] 组件语法/模板诊断、补全、悬浮、跳转与引用通过真实源位置显示，不泄露虚拟代码 URI。
- [ ] 缺少 TS 提供者时不另起私有 TS 引擎，不自动安装其他插件，状态准确。
- [ ] 候选历史后端的组件属性/插槽差异已经定位，不能以工具启动成功标记完整兼容。
- [ ] 真实工具退出后没有残留工作进程或可用旧引用。
