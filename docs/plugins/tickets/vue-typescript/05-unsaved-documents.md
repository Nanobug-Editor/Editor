# 05 关联脏文档同步与结果隔离

状态：拆分待确认，未发布。

## What to build

Vue、TS 与共享依赖的未保存修改以原生文档为唯一来源，同步到所有获准的分析上下文。辅助同步不改变主提供者或允许额外诊断发布；配置、映射、文档与实例变化后旧结果全部失效。

## Acceptance criteria

- [ ] 修改共享 TS 而不保存后，所有依赖它的 Vue 上下文使用新类型；磁盘原文保持不变。
- [ ] 同一服务上下文支持正确的逐文档 language ID 和 URI，保持模块解析与项目配置正确。
- [ ] 请求/诊断携带文档实例、revision、上下文和映射代次，拒绝乱序、取消和关闭重开结果。
- [ ] 大文件、多于既有文档枚举上限的项目、断流和队列溢出不会静默截断；可以重同步。
- [ ] 中文 IME、CRLF、UTF-16 代理对、外部 src 块的位置映射准确。
- [ ] 无第二份可写源文档或 Undo 栈，辅助上下文不抢占 JS/TS 界面结果。
