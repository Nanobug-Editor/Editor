## Acceptance criteria

- [ ] 方案 V01–V14 的适用场景全部有命令、结果、产物版本/摘要及原生证据。
- [ ] 针对性测试、格式检查、非 UI workspace 测试和 workspace 编译通过；真实 WASM ignored 测试显式执行。
- [ ] 真实编辑、补全选择、诊断、跳转、引用、重命名预览/取消/撤销、格式化与混合项目切换通过原生验收。
- [ ] 独立构建仅使用宿主管理的 SDK 缓存，不复制 SDK、不依赖宿主仓库内部路径、不调用历史 scripts。
- [ ] 规范与规格双轴审查完成；本任务变更与工作区已有改动分离。
- [ ] 实际支持清单、限制、历史版本保留与离线/回滚行为准确；未实测平台不标为通过。
- [ ] 只在对应工单验收、普通提交、推送和状态读回完成后关闭该工单；版本发布另行取得显式授权。
