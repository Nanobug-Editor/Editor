# 01 TypeScript 单项目分析与公开上下文

状态：拆分待确认，未发布。

## What to build

安装独立 TypeScript 插件后，普通 JS/TS 项目能使用补全、诊断、悬浮、跳转、引用、符号重命名和格式化。插件通过公开契约解析、描述和释放项目上下文，消费方不自行复制项目发现与引擎选择规则。先固定真实工具协作的最小版本组合与模块 ABI，再固化正式契约。

## Acceptance criteria

- [ ] 普通项目与无显式配置项目均能解析到可解释的 TS 上下文，独立于 Vue 是否启用。
- [ ] 从真实包进入公开管理器和宿主，观察七项基础语言能力；源文本通过原生文档接缝进入引擎。
- [ ] 同契约的最小消费夹具可以查询上下文、能力和引擎版本，无法借用提供者的私有句柄或权限。
- [ ] 缺失或不兼容引擎、明确工具路径错误均有结构化诊断，不静默替换用户选择。
- [ ] 工具层验证覆盖 Vue 适配模块、TS 引擎、组件属性/插槽、自动导入与重命名，并记录仍需后续工单解决的宿主缺口。
- [ ] 项目文件保持不变；生成类型与分析缓存进入私有目录或由适配层提供只读虚拟视图。
