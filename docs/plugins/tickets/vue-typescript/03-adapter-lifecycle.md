# 03 适配模块加载与联合撤销

状态：已发布 [#110](https://github.com/Nanobug-Editor/Editor/issues/110)，实施中。用户已授权自主安排顺序、并行实施与子代理；验收完成后才提交完成状态。

## What to build

TypeScript 提供者可以按公开授权加载其他插件导出的版本化适配模块。模块仅运行在受管分析进程；双方通过有界、可取消且绑定上下文的通信协作，宿主不解释特定语言的方法。

## Acceptance criteria

- [ ] 导出绑定不可变资源摘要、入口、ABI、来源和接收方，不暴露私有数据目录或接受任意路径代替授权。
- [ ] 模块加载用途和原生运行方式进入安装/更新授权，不承诺模块之间的 WASM 隔离。
- [ ] 分析通道协商协议与方法范围，具有关联请求、额度、超时、取消和背压，不用放大普通 RPC 限额绕过文档同步设计。
- [ ] 不兼容模块组合在独立工作进程中运行；权限/实例/上下文失效后拒绝旧调用。
- [ ] 导出者或接收者退出、更新、卸载时，先终止相关工作进程及受管子进程，再释放租约。
- [ ] 未知语言模块可以复用能力；同摘要缓存复用不混淆授权与资源所有权。
