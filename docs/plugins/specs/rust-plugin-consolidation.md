# Rust 语言、Cargo 与调试器合并

2026-10-09 用户确认开始实施。合并对象为 `plugins/rust` 0.5.1 和 `plugins/rust-debugger` 0.2.0；结果为 Rust 0.6.0，一个包、一个 `rust.wasm`、一个安装身份 `rust`。本次不提交、推送或发布版本。

## 包与生命周期

WASM 内部按 `language`、`cargo`、`debugger` 分工。保留语言识别、grammar、查询、图标、Rust Analyzer 项目发现、Cargo 模板、目标发现/构建和全部既有调试契约。异步事件同时交给相应模块，并由模块自己的请求或进程句柄匹配，避免同实例中的 Cargo 与调试互相消费回复。

宿主继续只识别公开契约，不按插件 ID、语言或适配器名称分支。`process 1.7`、`plugin.services 1.1` 和现有原生运行 Tab/终端由全部插件共享。插件版本提升为 0.6.0；SDK 版本、能力版本与包版本分别处理。

## 首次调试准备

新增通用 `dependencies 1.2`：固定原生服务可声明 `on_demand`，提供者契约的 `preparation[method]` 指定方法所需的服务 ID。安装不准备这些服务；方法开始前宿主在后台校验权限、准备声明的不可变依赖并保留缓存收据，之后才进入 WASM。普通激活、`StartService` 本身只查已准备缓存。

语言钩子的 `Context.preparing_dependencies` 区分安装计划查询与实际语言服务准备。Rust Analyzer 使用本地工具且没有下载计划，在前者跳过 SDK/项目发现；正常语言启动继续执行原逻辑。

Rust 的 `debug.session.start` 准备 `adapter`。CodeLLDB 保持固定 1.12.3、SHA-256 校验和包内原生桥。下载失败仅结束该请求，不禁用语言和 Cargo。取消、禁用、工作区撤销或实例更换使等待失效，不能启动迟到目标。缓存租约覆盖准备到进程取得自己的租约；不同方法的收据分别保留。首次调试超时预算为 180 秒；HTTP 下载仍受原有 120 秒限制。含原生安装器的依赖仍需安装流程中的独立具体确认，不能通过延迟准备绕过。

## 旧包有限替代

通用清单 `replaces` 声明旧身份、受支持版本、待迁移契约及新包中的布尔启用设置。Rust 声明替代 `rust-debugger >=0.1,<0.3` 的 `debug.session`，目标设置为 `debugger.enabled`。清单不能自己授权替代，安装确认展示替代身份及受影响会话，由宿主 `InstallControl` 记录批准。

- 保留原 Rust 安装身份、设置和既有 Cargo 配置。
- 旧调试器全局禁用映射为用户 `debugger.enabled=false`；原项目启用偏好映射为对应项目 `true`。已明确保存的新设置优先。
- 仅把明确选中旧调试器的相关用户/项目提供者选择改为 `rust`，其他提供者选择继续有效。
- 旧记录标记 `replaced_by=rust` 并停止运行；保留原私有文件、最后逻辑快照、原包和依赖收据，不给新插件跨旧数据访问权。
- 候选准备或激活失败保持旧实例；设置、提供者选择、替代历史及注册表随私有数据事务一起提交或恢复。准备期间旧版本状态发生变化时拒绝陈旧候选。

暂不支持跨作用域替代、含其他休眠工作区活实例的替代或未知旧版本；明确报错后由用户处理，不做隐式覆盖。替代过的旧记录不会普通启用；用户可卸载保留记录。有限替代不是通用跨插件私有数据转换 API。

## 平台与分发

项目描述支持可选平台原生步骤和资源，原生服务/提供者声明携带平台范围。Windows x86_64 包提供 CodeLLDB；macOS/Linux 打包跳过 Windows 桥、适配器、对应权限和替代声明，保留语言/Cargo。其他平台运行调试尚未实现或验收。

默认安装器只收录 `rust-0.6.0.zip`，不再构建或发行独立 `rust-debugger`。入口见 [Rust README](../../../plugins/rust/README.md) 和 [安装器说明](../../../installer/README.md)。历史验收保留原两包名称，不能作为合并版的新测试结果。

## 验证

真实包回归覆盖 Cargo、CodeLLDB 单目标输入/断点/局部变量/步进、并行调试、故障清理、延迟下载失败与取消、旧版替代和回滚。加载比较分别测量旧语言包、两个旧包、合并包的管理器恢复耗时和 WASM 字节，明确排除语言服务器及适配器启动。实际结果与平台限制见 [验收记录](../verification/rust-plugin-consolidation-2026-10-09.md)。
