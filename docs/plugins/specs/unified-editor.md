# 默认 Editor 与插件编辑节点统一

日期：2026-10-25。状态：统一功能实现及本机功能回归完成；追加复查发现的横向拖动瓶颈已在用户授权的 Base 0.8.0 本地补丁中修复，真实字体与原生拖动门禁通过，见[功能验收](../verification/unified-editor-2026-10-25.md)和[性能修复记录](../../ui/verification/internal-resize-performance-2026-10-25.md)。本机源码与候选包迁移，不提交、推送或发布。修复在 `codex/unified-editor` 工作区分支完成，以未提交差异合并回 main。

## 已确认目标

默认 `editor_ui::source_editor::Editor` 是唯一公开本地编辑控件。宿主普通编辑区、插件借用文档、带行边缘控件的文档以及插件文字快照使用同一个控件。内部按呈现、快照状态、输入限制和行边缘控件组织，继续使用锁定的 GPUI Base 原生编辑状态与行为。

## 内容及配置

插件仅有 `Kind::Editor(Editor)` 一种编辑节点。`source` 显式选择精确 `DocumentVersion` 或插件文字快照；`read_only` 收紧输入策略；`line_actions` 以整组可选配置挂载左右行边缘控件，空组保留边缘栏宽度；`changes` 表达快照差异范围；`sync_group` 与边缘控件独立。`Document.code_alignment` 继续控制整组的零字节补白对齐。

宿主适配器校验内容身份、作用域、版本、权限和实例生命周期后，向本地 Editor 传入准备好的 `EditorState` 与呈现配置。本地通用控件不解析工作区路径、不选择插件、不管理宿主文档会话。

- 文档来源复用唯一原会话，保留未保存文本、选择、IME、保存以及 Undo/Redo。仍只允许布局根部唯一的精确文档引用；关闭后重开同一路径产生新身份。
- 快照始终只读，没有文档、文件、保存或语言工具授权。每个快照至多 256 KiB、每个 UI 文档至多八个快照、总文字至多 1 MiB；标记与偏移必须是有界 UTF-8 位置。
- 文档只读挂载通过共享生命周期限制输入，最后一个持有者释放后恢复原策略；原本只读的来源不能被解锁。限制不复制文本或撤销栈。停用、隐藏、来源替换和视图释放都必须释放挂载。
- 行边缘控件由默认 Editor 根据实际原生几何裁剪和定位。文档动作还需核对精确版本与中文预编辑状态；快照动作绑定原 UI revision。改变 Editor 内容或动作必须推进 UI revision。
- 同步滚动及对齐保留原有限额、可见分支约束、过期撤销与明确回退，不写入补白文本。文档的通用装饰仍走已有归属明确的文档装饰接口。

## 契约迁移

`ui.code_editor` 与 `editor.layout` 升为主版本 2，基础协议仍为 7。`editor.actions` 1.0 仅在启用 `line_actions` 时需要。UI 能力不授予 `editor.write`；保存和程序化编辑继续走现有文档接口与权限检查。

三个旧节点从当前 SDK 移除，不保留旧节点执行分支。声明旧布局或代码编辑能力的包在公开兼容检查时明确拒绝并提示更新；既有设置和私有数据保持原存储标识。历史包字节保留为固定测试输入，新消费者使用新版本候选包。

迁移对象：宿主集成与原生测试、独立 Markdown、Image、Git，以及受影响的 SDK/布局夹具。候选通过配套宿主的 `--plugin-cargo` / `--plugin-package` 构建，不使用仓库源码路径依赖或复制 SDK。

## 验证接缝

沿用项目既定的公开包 → Manager → 宿主原生 UI 接缝。协议测试覆盖来源、限额、协商和过期事件；默认控件测试覆盖真实只读输入、复制、边缘点击及限制释放；宿主原生回归覆盖文档编辑、IME、Undo、滚动、对齐和来源撤销。实际候选包另行验证布局、Git 冲突以及只读快照。验收结果记录到对应 verification 文件，完成前不宣称全部交付。

编辑器布局变更还需显式运行使用真实字体的 Release `source_resize_frame_cost --ignored`，并以真实长文件分别验证横向、纵向原生分隔线；普通 workspace 测试不会执行这些 ignored 性能检查。本次门禁已通过，后续仍必须保留这些检查，不以编译、功能测试或空白布局的高刷新结果替代；同时报告跨换行断点的最长帧间隔。
