# 独占窗口拖放的整区替换

日期：2026-10-24。状态：已实现并完成功能验收；检查结果、固定候选和既有会话测试限制见[验证记录](../verification/exclusive-drop-replacement-2026-10-24.md)。

本规格补充[内部窗口单独占据](exclusive-dock-panels.md)。用户明确要求：普通窗口拖到独占窗口上，遮罩覆盖独占窗口的全部，放下后由新窗口完整替代；独占窗口拖到普通窗口上同样执行整区替换。Git 主窗口及原生终端默认独占，Git 提交窗口保持原声明。

## 拖放与可见结果

- 拖入或目标是独占窗口时，工具区域使用整区替换；覆盖完整目标区域的遮罩与最终占用范围一致，目标中间同样是有效落点。普通窗口之间继续使用原有边缘分屏，中心编辑区不成为替换对象。
- 独占窗口拖入一个普通组合时，遮罩覆盖目标实际所在侧的组合范围，落下后该侧仅显示拖入窗口。不能预览一个普通子窗格，最终却占据更大区域。
- 被替代窗口及其同区同伴保留实体、资源、显隐意图及底层布局；只临时隐藏。被替代不是关闭、删除或停用。
- 普通窗口替换独占窗口后，本次区域选择也必须只显示该拖入窗口，不能顺带显现原来被独占窗口遮住的普通同伴。该选择是用户布局意图，不修改插件声明或增加权限；会话恢复需保留此意图。
- 拖放前与悬停期间布局不变；Escape、无效落点及中途显隐/归属变化取消操作，不遗留替换选择。成功放下后更新布局及区域选择，不能仅移动窗口而使其仍被旧独占选择隐藏。
- 原有侧栏、中心编辑区及无关区域尺寸保留；搬出独占窗口后，来源区域按原有选择规则恢复。隐藏的同伴不会被错误加入拖动成员。
- 遮罩覆盖悬停时目标的完整现有范围；来源最后一个窗口搬走后，空区域按既有规则释放，目标可自然扩展到回收的空间，仍需填满扩展后的区域，不能遗留半块分屏。
- 通过普通窗口入口选择普通组合时仍遵循既有恢复规则；独占窗口重新选中时仍独占。持久化仅补充稳定窗口名称的替换意图，不保存第二棵布局树。

## 默认值

- 独立 Git 插件仅将 `history` 主面板声明为 `exclusive: true`，`staging` 提交面板及独立提交详情/冲突工作窗口不改。同步声明 `ui.panels >=1.2,<2`，新交付包递增版本，不覆盖旧包。
- 原生终端向既有通用 PanelPresentation 注册独占属性，沿用实际停靠侧与会话布局；不恢复终端插件，不按 Git 插件 ID 特判宿主拖放。

## 验收接缝

沿现有 GPUI 真实输入 → 生产 LocalDock → 实际遮罩边界/窗口可见性/会话恢复接缝补回归，不测试另一套模拟布局。覆盖双向拖入、中间与边缘落点、隐藏普通同伴、取消与失效、反复切换、保存后新实体恢复，以及普通分屏回归。实际 Windows 窗口补充遮罩与最终显示核对；被跳过场景不记为通过。

不自动改写用户当前安装或重启用户已有宿主。已有未提交源码和其他任务的变更保留，构建与测试输出隔离；提交、推送和发布不在当前授权内。
