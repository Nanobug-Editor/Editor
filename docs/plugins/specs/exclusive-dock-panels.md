# 内部窗口单独占据

日期：2026-10-18。状态：已实现，专项 GPUI 与 Windows 原生验收通过；工作区检查及扩展回归限制见验证记录。

用户要求内部窗口可声明“单独占据”：例如资源管理器与大纲原本组合显示在左侧，打开设置了该属性的暂存提交窗口时，左侧只显示暂存提交。该能力对所有插件公开，不以 Git 或其他插件 ID 决定行为。

- `Panel.exclusive` 为布尔值，默认 false。启用须显式要求 `ui.panels >=1.2,<2`（或 `^1.2`），排除不理解该属性的旧能力版本。
- 支持左、右、底部窗口；声明位置为 `editor`、`window` 时拒绝该属性。拖动后的行为按实际区域计算，中心编辑器始终保留。
- 普通窗口保留组合显示。打开独占窗口临时替换同区全部窗口，不修改其他区域、不删除原有布局、不覆盖原窗口的显隐意图。
- 同区最近显式打开的独占窗口获得区域；点击普通窗口入口则恢复普通组合。关闭独占窗口后，按仍有效的显隐意图和选择恢复。
- 原生窗口实体、内容资源、分割位置与尺寸由既有模块持有；被替换面板的公开可见性通知为 false。
- 右栏展开保留左栏宽度，仅缩小中间编辑区；普通组合与单独占据窗口使用同一规则，见[侧栏宽度验证](../../ui/verification/independent-sidebar-width-2026-10-19.md)。
- 会话仅新增区域选中窗口的稳定名称，不复制布局树。重开绑定新实体后恢复选择；禁用或卸载后剔除已失效的窗口。

API 使用与边界见 [Panel 源码注释](../../../crates/plugin-protocol/src/lib.rs)；能力维护资料见 [TOOLS.md](../../../crates/plugin-protocol/TOOLS.md)。该任务交付宿主通用属性，不自动修改或升级用户已安装插件。
