# 插件管理器共用布局

日期：2026-10-13。依据：本轮 grilling 的 Q1–Q7，用户确认整体实施。

本补充规定宿主管理窗口的呈现和交互；市场目录、审核、权限、安装事务与发布规则继续以独立市场项目的现行规格为准。它替代旧插件管理与日志规格中“因市场未开放而禁用四个信息 Tab”的条件。

## 已确认行为

- 已安装与插件市场共用侧栏、搜索框、双下划线 Tab、列表行、固定详情头、操作区、详情 Tab 和独立正文滚动区。布局在同一组组件中实现。
- 筛选图标位于市场搜索框内部左端，与输入共用背景、边框；面板在搜索框下方展开、左对齐，提供分类、标签、排序及清除筛选。非默认条件有标记。已安装搜索沿用原有匹配行为。
- 详情 Tab 顺序仍为概览、最新变化、评价、其他版本、其他信息、运行日志；按实际数据启用。评价继续不可用；运行日志仅对已安装实例开放。
- 概览在已安装模式显示本地版本 README，市场模式显示所选审核版本 README；更新记录、版本历史与维护者、来源、许可、权限、兼容性和下载统计分别进入对应 Tab。市场正文保持现有无外部图片加载的渲染边界。
- 市场头部明确显示浏览版本和已安装版本；安装/更新面向所选审核版本，全局/项目启停、重启、卸载和日志面向本地实际实例。管理操作共用已安装页的权限、忙碌状态、确认与生命周期入口。操作后保持当前市场页面并同步实际状态。
- 市场保留仅升级规则；同版、更旧、不兼容、撤回或失去最新目录授权的版本可浏览，不能安装。离线目录不影响本地实例管理和本地导入。
- 固定头部与详情 Tab 不随正文滚动；窄窗口和字体/显示缩放保持操作顺序和可访问区域。搜索、页面、插件或详情 Tab 切换按现有重置规则处理；筛选和排序算法复用现有市场搜索。
