# 原生画布列宽调整

2026-10-24。通用公开能力 `ui.canvas 1.6`，不增加权限，不包含 Git 专属规则。

`Canvas.column_resize` 声明 `ColumnResize { epoch, x, widths, minimum, bindings }`。2～32 列，固定总宽度，内部边界两侧各 5 个逻辑像素为透明拖动区域，使用系统横向调整光标。拖动仅改变相邻两列，并受各列最小宽度约束。绑定项按当前绘图索引指向 `Paint::TextBox`；每项只绑定一次，最多 32000 项，越界、非文本绑定、非有限尺寸及不匹配的向量均拒绝。网格、IME 锚点和变换视口不能组合此能力。

宿主逐帧移动并伸缩绑定文本矩形，保留原始内边距，按原生文字度量与省略规则绘制。移动不通知 WASM、不重建 SVG，不刷新兄弟面板。释放或有效失焦后仅发送一次 `CanvasEvent::ColumnsResized { epoch, widths }`，插件决定如何保存列宽；无变化不发送。没有声明此能力的画布沿用原有指针事件。

`epoch` 表示列含义的当前身份，替换后必须更新，包括 A→B→A。普通重绘和滚动保持身份；旧绘图回包不能回滚正在拖动或等待确认的原生宽度。提供者返回匹配宽度后确认完成。禁用、移除、内容身份／外部几何改变及作用域撤销结束原生手势，不能向新来源发送旧输入。

完成事件可跨过同一身份的旧绘图 revision，但必须仍为当前有效节点，列数、最小宽度及总宽度均匹配。未来 revision、过期 epoch、模态遮挡及编辑器来源手势不使用此例外。SDK 类型和校验见 `crates/plugin-protocol/src/ui/canvas/columns.rs`，本地控件位于 `crates/editor-ui/src/column_resize/`。

## 原生视口宽度适配（1.11）

2026-10-27。`ColumnResize.viewport` 可选声明 `ColumnViewport { width, flexible, span_paints }`，选择该字段必须协商 `ui.canvas >=1.11,<2`；不增加权限。不填写时保留上面的固定总宽行为。

- `width` 是这一份绘图使用的参考宽度，包含列之外的左右留白，可能大于实际视口；须为有限正数且不超过 1,000,000，所有列必须容纳在该宽度内。提供者发布未压缩的首选列宽及最小宽度，窄窗口仍保留该偏好，不能把已经压缩过的结果再作为首选值回传。绑定文本与整行 Fill 必须都使用这一参考宽度，防止重复应用尺寸差值。
- `flexible` 是吸收视口宽度变化的列索引。该列先增长或缩到其最小宽度，再按比例收缩其他列超出最小值的部分；可用宽度小于所有最小值之和时，最小值整体缩放。宿主保留原始偏好及其基准宽度，窄后重新变宽不累计舍入误差或遗失原宽度。
- `span_paints` 是最多 32,000 个不重复的 `Paint::Fill` 索引。它们的宽度随表格总宽变化，适用于选中行背景；内部两列调整不改变其宽度。越界、重复或非 Fill 索引明确拒绝。

原生布局每帧以实际视口宽度投影文本与行背景；不重建 SVG、不调用 WASM，也不改变滚动身份或行选择。提供者仍接收既有 `Resize` 并可更新自身绘图，迟到的较宽或较窄快照都基于各自声明宽度再次投影到当前原生视口。光标命中条使用同一列边界。

原生内部列拖动仍只在释放时发送一次 `ColumnsResized`。启用视口适配后，该事件可能先于插件处理最新 `Resize`；用新列总宽与声明的固定留白推得实际视口宽度，并按同一窄视口规则校验最小宽度。仍校验 epoch、列数、非负有限值、最大宽度和有效节点，不接受过期语义身份。没有启用该选项的提供者继续要求总宽与当前绘图一致。

外部原生几何变化会取消正在按住的内部列手势；仅收到较旧尺寸的绘图回复不代表原生几何又变了一次，不取消当前手势。完成后尚未确认的列宽偏好可跨外部宽度变化保留，收到匹配确认后再接纳后续提供者调整。
