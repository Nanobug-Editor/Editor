# 原生画布列宽调整

2026-10-24。通用公开能力 `ui.canvas 1.6`，不增加权限，不包含 Git 专属规则。

`Canvas.column_resize` 声明 `ColumnResize { epoch, x, widths, minimum, bindings }`。2～32 列，固定总宽度，内部边界两侧各 5 个逻辑像素为透明拖动区域，使用系统横向调整光标。拖动仅改变相邻两列，并受各列最小宽度约束。绑定项按当前绘图索引指向 `Paint::TextBox`；每项只绑定一次，最多 32000 项，越界、非文本绑定、非有限尺寸及不匹配的向量均拒绝。网格、IME 锚点和变换视口不能组合此能力。

宿主逐帧移动并伸缩绑定文本矩形，保留原始内边距，按原生文字度量与省略规则绘制。移动不通知 WASM、不重建 SVG，不刷新兄弟面板。释放或有效失焦后仅发送一次 `CanvasEvent::ColumnsResized { epoch, widths }`，插件决定如何保存列宽；无变化不发送。没有声明此能力的画布沿用原有指针事件。

`epoch` 表示列含义的当前身份，替换后必须更新，包括 A→B→A。普通重绘和滚动保持身份；旧绘图回包不能回滚正在拖动或等待确认的原生宽度。提供者返回匹配宽度后确认完成。禁用、移除、内容身份／外部几何改变及作用域撤销结束原生手势，不能向新来源发送旧输入。

完成事件可跨过同一身份的旧绘图 revision，但必须仍为当前有效节点，列数、最小宽度及总宽度均匹配。未来 revision、过期 epoch、模态遮挡及编辑器来源手势不使用此例外。SDK 类型和校验见 `crates/plugin-protocol/src/ui/canvas/columns.rs`，本地控件位于 `crates/editor-ui/src/column_resize/`。
