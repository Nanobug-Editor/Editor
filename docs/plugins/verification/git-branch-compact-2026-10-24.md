## 实现

- 独立 Git 的 `tree_children` 为首次页面和增量 patch 提供同一顺序：当前本地分支叶子优先，其余沿用目录／名称顺序，排序发生在分页之前。只匹配实际 `current_ref`，不匹配历史 filter、远程同名分支或游离 HEAD。稳定节点 ID 不变。
- 使用独立插件自有 `current-branch.svg`／`current-branch-dark.svg`，透明圆孔与不同亮度的黄色适配选择、悬停和深浅主题。说明文本仍使用现有中英文“当前分支”。
- 每项元数据左右各留 4px；标签 End、作者和时间 Start。作者与日期列默认由实际原生 advance 决定，作者最大自然宽度 240px，超长内容按原生文本区域省略；用户手动宽度保持优先。默认布局先保留时间和作者所需宽度，再扩展标签列；极窄视口仍受既有最小宽度约束。手动拖动继续按相邻列及最小宽度约束处理。
- 自动尺寸按唯一作者增量观察，每批最多 64 个有界姓名样本；普通滚动不重扫已有历史、不重复请求字宽。历史身份和字体变化重新取样；批次 ID 拒绝旧字体／旧历史回包。原始作者内容仍保留在提交详情。
- 通用 `ui.canvas 1.5` 增加 `Canvas.measure_text` 和 `CanvasEvent::TextMeasured`，按样本组返回最宽单行原生 advance。16 组／256 样本／64 KiB 总文本及每样本 4096 字节；样本还计入整份 UI 文本预算。结果使用精确场景校验，不沿滚动 epoch 例外越过 revision。原生画布缓存相同请求／字体，并沿用被拒绝测量的重试路径。
- 公开类型、版本、校验、SDK 文档和宿主内嵌 SDK 导出同步更新；本地文字度量仍集中于 `editor-ui`，生产宿主没有 Git 专属分支。协议 7、既有安装权限及十六项拓扑颜色设置保持。
- 基线插件在其他会话中已更新至 0.1.37，包含新的提交表单和连续分页；本轮保留其行为并形成 0.1.38，不把其他会话变更计为本次成果。
