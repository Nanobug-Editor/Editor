## 实现

- 通用对齐控件利用原生完整行位置，并通过原生滚动边界取得实际横向宽度，不再为普通短行重复铺满屏幕外文本。需要跳到文件中部时先挂载目标附近的原生输入窗口，再用真实字形位置完成定位；不根据字符数猜坐标。
- 比较标签只保留轻量滚动位置。关闭当前展示仍撤销输入、绘制和资源；重新激活等当前排版完成后恢复位置。相同文件、来源版本及折叠描述的重复打开保留当前展示。
- Git 插件合并同一目标的进行中请求；已完成且文档观察仍有效的不可变历史比较使用原有来源。提交、父提交和路径参与身份判定；失效文档仅通过普通公开接口重新准备一次。工作区/暂存区内容仍按既有新鲜度路径读取。
- 折叠偏好存于用户 `editor.json`，旧记录和新用户默认折叠。只在明确改变全部展开/折叠选择时保存；文件/标签切换不写设置。单个区域的展开不改变全局默认，保留标签的局部选择；之后明确改变全局选择时，其他文件下次显示采用新选择。
- 只读来源刷新仍按公开契约增加版本；正文 Rope 未改变时保留原生行布局。同一工作区文件再次请求比较前同步保留视图的当前版本，避免无变化刷新误触发重建。
- 原生编辑请求的变更事件提交后，唤醒插件执行线程处理已有回复，消除逐次等待 30 ms 空闲轮询的延迟。唤醒只占一个可合并标志，不增加输入队列元素、不改变顺序，消费后恢复正常休眠。
