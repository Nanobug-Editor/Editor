# 消息按钮三色提醒

日期：2026-10-24。依据：本轮用户明确要求和[宿主消息规格](../specs/host-messages.md)。

## 行为

- 普通信息为蓝点，警告为橙点，危险／错误为红点；消息按钮和“更多窗口”溢出入口采用相同颜色。
- 尚未确认的消息以最高等级为准：Error > Warning > Info。新到低等级消息、重绘和历史淘汰都不会降低提醒；不增加第二份消息历史。
- 打开消息窗口或清空确认已有提醒；之后到达的任意等级消息重新提醒。收起、主题切换及改变宽度不确认消息。
- 仍由既有宿主发布入口明确决定消息等级和收录范围。日常操作保持原有安静策略；不改变插件日志、抢焦点或自动展开窗口。
- 提示色集中在本地 `MessageLevel::reminder_color`，使用深浅主题对应的蓝／橙及已有危险色；不改变全局警告配色。中英文未读提示改为适用于全部等级的“有新消息”。
