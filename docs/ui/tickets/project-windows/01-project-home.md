## What to build

用户无参数启动后看到真正没有工作区的原生首页，通过文件夹选择或最近项目进入编辑；首次打开陌生项目选择信任或受限模式。用户可以安全关闭项目回到同一窗口的首页，再打开另一个项目，或关闭最后一个窗口退出。

一次交付“首页 → 选目录 → 信任 → 编辑 → 保存/取消/清理 → 首页 → 重新打开”的完整路径，包括最近项目及会话持久化。此阶段不开放第二个并行项目窗口；多个项目同时运行由 02 交付，不能把本单完成称为整个 #102 完成。

## Acceptance criteria

- [x] 无参数启动显示首页，不以当前目录、用户文档目录或虚假目录建立占位工作区，不为首页启动项目插件、语言服务、终端或文件监听；原有显式目录和文件参数启动仍可用，文件参数仍定位目标文件。
- [x] 通过原生目录选择器选择普通文件夹即可打开，不要求 Git 或专用项目文件；首页在原窗口进入项目。取消选择、信任取消、路径无效和不可访问均保留原视图、文档及已有数据，并给出必要错误，不回退打开当前目录。
- [x] 最近项目保存于本机用户数据，展示名称、完整路径、最近打开顺序并去重，重启后保留。移除只删除记录；目录缺失时提示并保留记录，不创建目录、不删除项目文件、信任或私有数据。
- [x] 没有本机信任记录时提供“信任并打开 / 以受限模式打开 / 取消”，持久保存选择并沿用既有有效记录。受限模式可编辑，但不启动插件和语言工具、不使用项目工具路径；项目文件不能授予信任或权限。
- [x] 新增“关闭项目”入口，完成当前项目清理后回到同一窗口首页。复用同一关闭流程处理最后窗口关闭及单窗口退出，不把资源清理中的直接退出调用用于“关闭项目”。
- [x] 关闭判断前应用待提交输入；脏文档提供“保存并关闭 / 放弃修改 / 取消”。保存失败或冲突阻止关闭，文本、编辑状态和窗口保留；不能以会话保存代替真正的文档保存。
- [x] 当前项目仍有运行任务或终端程序时，确认后才停止所属程序；拒绝停止或取消关闭时仍可继续编辑和运行。释放所属监听、语言服务、终端、插件实例、请求、订阅及文件传输，清理失败可见，不假报成功。
- [x] 关闭项目后再打开另一个项目，旧工作区或旧实例的迟到结果不得进入新项目；DocumentSession 与 EditorState 保持唯一文本和会话 Undo/Redo 来源。
- [x] 重新打开受信任项目恢复已保存标签、活动文件及布局，不恢复未保存文本和上次程序；普通启动仍进首页。保留既有持久化标识、用户设置和私有数据，不以清空数据实现迁移。
- [x] 新增界面采用现有 GPUI 原生行为与本地外观，保留中英文、深浅主题、键盘、焦点、中文 IME、最近项目滚动及缩放；对话原型的场景选择器不进入产品。
- [x] 完成下述针对性、原生交互及每单交付检查，记录实际证据；被跳过的测试或尚未实现的多窗口/外部启动场景不能报告通过。

## Implementation and verification

### 先完成必要预重构

在添加首页行为前，先整理启动目标解析、无项目状态、窗口与项目资源收尾的边界；将“保存决定”和“执行清理”分开，保留后续应用退出的汇总入口。用现有单项目启动、编辑、终端和保存场景确认行为未退化，再接入新界面。

不另建第二套会话或文档状态，不新增仅用于转发的包装层；统一打开/关闭入口同时服务生产界面和应用级测试。不要提前实现 02 的完整多作用域运行时或 03 的跨进程传输。

### 测试主责与最小回归集

- 详细覆盖 P02、P05–P09、P15、P16、P19；覆盖 P01 的首次无参数启动，以及 P13、P14、P17 的单项目基础行为；P24 覆盖本单新增界面。
- 通过现有 GPUI 应用级路径驱动真实窗口、目录选择结果、文档输入和关闭操作。共享临时工作区、隔离 profile、可控原生程序及现有包夹具，不建立测试专属业务入口。
- 将路径成功/无效/取消、最近记录操作、信任三种选择、未保存三种选择和保存失败组织成有独立断言的参数化或分组用例；不为每个按钮复制整个启动过程。
- 用一条“打开 → 编辑 → 关闭取消 → 保存并关闭项目 → 再次打开并恢复”的原生主流程，补充受限模式、中文输入和清理失败等必要边界。自动化覆盖充分的相同逻辑不再逐项重复人工验证。
- 后续 02 复用本单公共规则及夹具，仅增加多窗口并存/退出条件；03 只用代表性项目验证外部入口接线，不重跑全部首页、最近记录、信任和保存组合的人工作业。

### 交付检查与证据

先运行受影响模块的针对性测试。最终候选稳定后集中执行一次 `cargo fmt --check`、`cargo test --workspace --exclude editor-app`、`cargo check --workspace`、相关 `cargo test -p editor-app <测试过滤词>` 及必要原生交互验收。

记录候选提交或工作区快照、实际命令、结果、原生观察与未验证项；只有后续改动、失败或未解除风险才扩大/重跑相关验证。真实包或原生夹具的 ignored 测试按现行直接构建入口准备并显式执行，不擅自安装工具链。
