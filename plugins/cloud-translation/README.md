# 云翻译 / cloud-translation

独立 SDK 消费者，只通过公开通用 HTTP、系统密钥、私有缓存、定时器和原生交互。

- 在插件菜单使用「安全输入密钥」，密码输入结果写入系统 Credential Manager；仅支持 Token/API Key，不做 OAuth 或 AI。
- 「查询」使用本机受控端点 http://127.0.0.1:18906/translate（POST 文本）。端点不可用时显示传输错误；未启动任何辅助进程。
- 持续接收期间每 25 ms 拉取少量分块并显示进度；「取消查询」撤销 HTTP 和定时器。用户点击原生进度的取消按钮具有同样效果。
- 「刷新」使用 300 ms debounce；请求仅在实际查询期间启动，不在空闲状态后台联网。「读取缓存」读取本插件上次结果。
- 「删除密钥」只删除本插件的 api-token。禁用保留安全密钥与缓存，临时数据和活动资源由宿主撤销。

Windows 使用系统保护；其他平台密钥接口明确返回不支持，绝不保存到普通文件。测试只使用假的 Token 和受控端点。
