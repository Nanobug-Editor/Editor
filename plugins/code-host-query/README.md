# 代码托管查询 / code-host-query

独立 SDK 消费者，只通过公开通用 HTTP、系统密钥、私有缓存、定时器和原生交互。0.1.2 使用协议 7、最低宿主 0.1.0，并要求 `configuration >=1.1,<2`；宿主版本与能力版本分别校验。默认按需求激活，安装本包不在空闲时启动查询或后台计时器。

- 在插件菜单使用「安全输入密钥」，密码输入结果写入系统 Credential Manager；仅支持 Token/API Key，不做 OAuth 或 AI。
- 「查询」使用本机受控端点 http://127.0.0.1:18907/repositories（GET）。端点不可用时显示传输错误；未启动任何辅助进程。
- 持续接收期间按 `poll_interval` 拉取少量分块并显示进度，默认 25 ms；「取消查询」撤销 HTTP 和定时器。用户点击原生进度的取消按钮具有同样效果。
- 「刷新」使用 300 ms debounce；请求仅在实际查询期间启动，不在空闲状态后台联网。「读取缓存」读取本插件上次结果。
- 最大 65,536-byte 响应保留完整缓存与可见结果；大文本在原生滚动区按 Unicode 边界分为多个 Text，非 UTF-8 的替代字符也不会溢出单个控件配额。
- 「删除密钥」只删除当前 `keyRef` 指定的本插件密钥，默认 `api-token`。禁用保留安全密钥与缓存，临时数据和活动资源由宿主撤销。

配置只保存插件私有的策略和密钥引用：

| 设置 | 默认值与范围 | 作用域和生效方式 |
| --- | --- | --- |
| `poll_interval` | 25 ms；10–1,000 ms | 用户或项目覆盖；Changed 重设现有拉取 timer，保留 owner 和 HTTP 流 |
| `timeout` | 30,000 ms；100–120,000 ms | 用户或项目覆盖；用于下一次 HTTP 请求，已有传输保留原 deadline |
| `keyRef` | `api-token`；至多 128 UTF-8 bytes、无控制字符 | 仅用户；自己的系统密钥键，空值表示未配置/不发送 Authorization |

校验还要求 `timeout >= poll_interval`；失败保持旧有效配置和实例。热变更不自动重新发送查询，不能撤销远端已发生的效果。改变密钥引用会取消尚未完成的密码输入，避免将旧输入写到新的引用。Token/API Key 的实际值只通过密码交互写入系统安全设施，不进入普通配置、日志、缓存或 Snapshot；引用不会授予网络目标权限，也不能选择其他插件的密钥命名空间。

Windows 使用系统保护；其他平台密钥接口明确返回不支持，绝不保存到普通文件。测试只使用假的 Token 和受控端点。
